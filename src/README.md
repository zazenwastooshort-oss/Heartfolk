# src: the game

TypeScript, built by Vite into one file, `dist/index.html`. Rules from `CLAUDE.md`: systems change state, rendering only reads it, the UI only sends commands, modules announce events.

Tests are in `tests/`; the long headless run in `tests/play.test.ts` is the start of the plan's multi-day simulation check. Real saves frozen from each release (`tests/fixtures/saves/`, made by `tools/freeze_saves.mjs`) are loaded by `tests/saves.test.ts`, so an update never loses a player's game. `tests/architecture.test.ts` enforces the module boundaries: each folder may only import from the layers listed there, the simulation layers may not touch three.js or the page, and `render/` and `ui/` may not assign to game state. If it fails, move the code to the right layer rather than loosening the rule.
