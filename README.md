# Hearthfolk

An idle skilling game you leave running like an ant farm: you send your character to work in a living village, they level up the long OSRS way, and their earnings grow the world. Pre-production.

- `CLAUDE.md`: instructions Claude Code reads at the start of every session.
- `docs/PLAN.md`: the design and development plan, and the list of open questions.
- `docs/CHANGELOG.md`: what changed and when.
- `prototypes/`: two playable prototypes; double-click either file to open it in a browser.
- `src/`, `tests/`: the game itself (TypeScript); `npm run build` writes the playable `dist/index.html`. See `src/README.md`.
- `assets-src/`, `tools/`, `assets/`, `demos/`: the art pipeline and playable tests; each folder has its own short README.

To work on the game, open the Claude desktop app, go to the Code tab, choose Local, select this folder, and say: "Read CLAUDE.md and let's start."
